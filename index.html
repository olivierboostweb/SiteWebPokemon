PokéQuest 90s: collection de cartes Pokémon connectée

Cette section sert de support pour présenter le site: son idée, son interface, sa base de données, ses fonctions de gestion et son déploiement sur Vercel.

01

Introduction

PokéQuest 90s est un site web au style rétro qui permet de consulter une collection de cartes Pokémon et de les organiser par génération.

Durée: 45 secondes. Présenter le thème, le style années 90 et le but du projet.
02

Objectif du site

Le site ne sert pas seulement à afficher des cartes: il montre comment une interface web peut communiquer avec une vraie base de données modifiable.

  • Afficher les générations Pokémon.
  • Voir les cartes avec leurs détails.
  • Ajouter, modifier et supprimer des cartes.
Durée: 1 minute. Expliquer la différence entre un site statique et un site connecté.
03

Expérience utilisateur

L'utilisateur navigue avec des onglets simples: accueil, générations, ajout, collection complète et informations techniques.

Navigation rapide Aperçu de carte Recherche
Durée: 1 à 2 minutes. Montrer les onglets et cliquer sur une carte.
04

Base de données

Les données sont séparées en tables: générations, séries, boosters, raretés et cartes. Cette structure évite de tout mélanger dans un seul fichier.

generation serie booster rarete tbl_carte
Durée: 1 à 2 minutes. Décrire rapidement les tables et les relations.
05

Fonctions modifiables

La collection peut évoluer directement depuis le site. Une nouvelle carte est envoyée à l'API, puis enregistrée dans PostgreSQL.

  • Ajout d'une carte avec formulaire.
  • Modification depuis l'aperçu.
  • Suppression si une entrée est incorrecte.
Durée: 1 à 2 minutes. Faire une petite démonstration d'ajout ou de modification.
06

Déploiement Vercel

Le projet utilise une API serverless sur Vercel et une base PostgreSQL Neon. Cela permet au site d'être en ligne tout en gardant une base de données persistante.

Interface /api PostgreSQL
Durée: 1 minute. Expliquer que Vercel héberge le site et Neon garde les données.
07

Conclusion

PokéQuest 90s combine une identité visuelle rétro, une navigation simple et une vraie base de données. Le projet peut être amélioré avec des comptes utilisateurs, des images uploadées et des filtres plus avancés.

Durée: 45 secondes. Résumer ce qui fonctionne et ouvrir sur les améliorations possibles.
